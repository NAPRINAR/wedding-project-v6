# Свадебный сайт Նարեկ & Մոնիկա — сводка прогресса

Дата свадьбы: **26.10.2026**. Репозиторий: [NAPRINAR/wedding-project](https://github.com/NAPRINAR/wedding-project).
Прод: `https://wedding-project-flax.vercel.app`.

## Технологический стек

- **Vite** (vanilla JS, без фреймворка) + чистый CSS.
- **GSAP** — анимации появления, scroll-reveal.
- **Lucide** (`lucide-static`, лицензия ISC) — все иконки, вместо самодельных SVG.
- **Google Fonts**: Noto Serif Armenian + Noto Sans Armenian (единственная официальная армянская пара на Google Fonts; при необходимости кириллица берётся автоматическим fallback'ом из базовых Noto Serif/Sans).
- **Vercel** — хостинг + serverless-функции (`/api/*`).
- **Vercel KV (Upstash Redis)** — хранение ответов RSVP.
- i18n — простой объект переводов (`src/i18n.js`), ключи `hy`/`ru`, язык переключается кнопкой, по умолчанию армянский.

## Что сделано

- **Intro-конверт**: экран с конвертом на золотисто-кремовом градиенте, клик → клапан меняется на «открытый» вид (плоская форма, без 3D-поворота — от 3D отказались, глючило), восковая печать (перекрашенное CSS-фильтром реальное фото, а не рисованная), письмо выезжает из кармана за клапаном, затем разрастается на весь экран (реализовано через реальные координаты `getBoundingClientRect()` + анимация `top/left/width/height`, а не `transform:scale` — так же глючило по краям), фон становится белым, открывается сайт. Показывается один раз (localStorage), уважает `prefers-reduced-motion`.
- **Hero**: кроссфейд-слайдер фото (`hero-1..4.jpg`, стоковые с Unsplash), имена, дата.
- **Блок приветствия**: текст + неделя-календарь с золотым выделением дня свадьбы (26 октября, понедельник).
- **Программа дня**: таймлайн с иконками (Lucide), кнопки Google Maps у церкви и ресторана.
- **Дресс-код**: блок «дресс-кода нет».
- **RSVP-форма**: имя, буду/не буду, сторона жениха/невесты → `POST /api/rsvp`.
- **Уведомления в Telegram**: несколько получателей через `TELEGRAM_CHAT_ID` (через запятую), команда `/list` в самом боте показывает сводку без перехода по ссылке.
- **Сводка ответов**: `/api/rsvp-stats?key=...` — HTML-страница со счётчиками и списком, данные пишутся в Vercel KV при каждом ответе (`api/_lib/rsvp-summary.js` — общая логика подсчёта для веб-страницы и Telegram-команды).
- **Мобильная адаптация**: уменьшены кнопки карт, футер компактнее, устранён случайный отступ у формы (баг с приоритетом CSS-правил).
- **[ЭКСПЕРИМЕНТ, не запушено]** Общий фон на всю страницу: фото из hero стало `position:fixed` позади всего контента; расписание/дресс-код/приветствие/форма — прозрачные (0.8 alpha, единая прозрачность), футер остался полностью непрозрачным. Ждёт вашей оценки перед пушем.

## Архитектурные решения (и почему)

- **Свой код вместо сторонних иллюстраций для конверта** — готовых SVG под анимацию открытия не нашлось, форма конверта — простая геометрия (прямоугольник + треугольник), это не «иллюстрация», а конструкция под анимацию.
- **Критический CSS продублирован в `<head>`** (`index.html`) — Vite в dev-режиме подключает CSS через JS с задержкой, из-за чего конверт на миг мог показаться без стилей. Внешний `src/style.css` остаётся основным источником правды; блок в `<head>` нужно обновлять вручную при правках intro/конверта.
- **Vercel KV вместо Google Sheets/своей БД** — минимальная настройка (пара кликов в панели Vercel), достаточно для масштаба свадебного сайта.
- **`api/_lib/rsvp-summary.js`** — общая логика чтения/подсчёта ответов, чтобы веб-страница и Telegram-бот не расходились в подсчётах.
