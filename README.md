# Wedding Project — Մոնիկա & Նարեկ

Свадебный лендинг: армянский язык (по умолчанию) с переключением на русский, анимации,
адаптив под мобильные, форма RSVP с уведомлением в Telegram.

## Локальный запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Форма RSVP локально работать не будет без
Vercel CLI (см. ниже) — серверная функция `/api/rsvp` доступна только через `vercel dev`
или после деплоя.

## Настройка Telegram-уведомлений

1. Создайте бота через **@BotFather** в Telegram → `/newbot` → получите токен.
2. Напишите боту любое сообщение, затем откройте в браузере:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — найдите `"chat":{"id": ...}` — это `TELEGRAM_CHAT_ID`.
3. Эти два значения нужно добавить как переменные окружения (см. деплой ниже).
   Файл `.env.example` показывает, какие именно — реальные значения никогда не коммитятся в git.

## Деплой на Vercel

1. Установите Vercel CLI (один раз): `npm install -g vercel`
2. В папке проекта: `vercel` — привяжет проект к вашему аккаунту Vercel и задеплоит.
3. В панели Vercel → ваш проект → **Settings → Environment Variables** добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Передеплойте (`vercel --prod`), чтобы переменные подхватились.

Либо просто импортируйте GitHub-репозиторий `NAPRINAR/wedding-project` через
[vercel.com/new](https://vercel.com/new) — Vercel сам определит Vite-проект и папку `api/`.

## Сводка по ответам (кто придёт, сколько всего)

Каждый ответ на форму сохраняется в подключённое хранилище (Storage → KV/Upstash Redis
в панели Vercel — подключается один раз, в пару кликов). Посмотреть сводку:

```
https://<ваш-сайт>.vercel.app/api/rsvp-stats?key=<ADMIN_KEY>
```

`ADMIN_KEY` — любой пароль, который вы сами придумаете и добавите как переменную
окружения (см. `.env.example`). Без правильного `key` в ссылке страница не откроется —
гости её не увидят.

Ту же сводку можно получить прямо в Telegram, без ссылки: напишите боту `/list`
(один раз после деплоя нужно подключить это — см. ниже).

### Подключить команду /list в боте (один раз)

После деплоя откройте в браузере (подставив свой токен и адрес сайта):

```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<ваш-сайт>.vercel.app/api/telegram-webhook
```

Должно вернуться `{"ok":true,"result":true,...}`. Дальше просто пишете боту `/list` —
он отвечает списком и счётчиками. Отвечает только тем chat_id, что в `TELEGRAM_CHAT_ID` —
остальным сообщениям боту он не отвечает.

## Что нужно доделать

- **Адреса для кнопок Google Maps**: в [src/i18n.js](src/i18n.js) в объектах `schedule`
  найдите `mapQuery` для церкви и ресторана — сейчас там название площадки, замените
  на точный адрес, когда он будет.
- **Фотографии**: в `public/images/` сейчас лежат бесплатные стоковые фото (Unsplash) —
  замените на свои файлы с теми же именами (`hero-1.jpg` … `hero-4.jpg`, `details.jpg`, `rsvp.jpg`)
  или на любые другие, поправив пути в [index.html](index.html).

## Структура

```
index.html        разметка страницы
src/style.css     стили, палитра, адаптив
src/main.js       язык, слайдер, анимации (GSAP), форма RSVP
src/i18n.js       тексты на армянском/русском + программа дня
api/rsvp.js       серверная функция: получает форму, шлёт в Telegram
public/images/    фотографии (плейсхолдеры)
```
